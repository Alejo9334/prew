Publicar nuevo cuadro en GitHub

El editor generará un solo archivo de publicación con la imagen de referencia, las capas PNG y los ajustes actuales. No se necesitan carpetas manuales ni contraseñas en este panel.

Solo puedes agregar cuadros nuevos por este flujo. Si el ID ya existe en el visor publicado, no sobrescribiremos su contenido. La publicación se confirma en GitHub con una cuenta autorizada.

Abrir GitHub para subir el JSON

En GitHub, sube el JSON descargado a la carpeta proyectos/pendientes/ de la rama de desarrollo y confirma «Commit changes». El flujo automático compilará el reconocimiento y optimizará las imágenes. La vista Preview se actualizará tras su despliegue.

Actualizar experiencia publicada

Actualiza capas PNG, posiciones, profundidad, rotaciones, sombras y animaciones de este cuadro. Se conserva la misma imagen de referencia para que el cliente siga escaneando el mismo cuadro.

Se genera un JSON seguro de actualización. Debes subirlo a GitHub y confirmar el commit para publicar; guardar el borrador no actualiza al cliente. La imagen física de reconocimiento no puede cambiarse con esta opción.
